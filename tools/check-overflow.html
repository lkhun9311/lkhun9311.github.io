가로 넘침 검사

수동 검사다. 사이트 루트에서 정적 서버를 띄우고 이 페이지를 열면 결과가 <title> 에 들어간다. 헤드리스로는 이렇게 돌린다.

python3 -m http.server 8899
google-chrome --headless=new --disable-gpu --no-sandbox --virtual-time-budget=20000 \
  --dump-dom "http://127.0.0.1:8899/tools/check-overflow.html" | grep -o '<title>[^<]*</title>'

무엇을 보는가: 섹션 인덱스의 태그 레일과 기사의 목차는 컨테이너 바깥 여백으로 밀려 나가 있다(--rail-shift · --toc-shift). 미는 거리를 남는 여백보다 크게 잡으면 넓은 화면에서 가로 스크롤이 생기는데, 좁은 화면에서는 안 생겨서 눈으로는 잘 안 잡힌다. 그래서 폭을 바꿔 가며 scrollWidth > clientWidth 를 직접 잰다.

iframe 안에서는 100vw 가 iframe 폭이므로, 폭만 바꿔 주면 뷰포트를 바꾼 것과 같다.
