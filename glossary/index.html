용어집 9

글에 나오는 용어를 하나씩 풀어 둡니다. 정의 한 줄로 끝내지 않고 왜 있는지와 어떻게 도는지까지 적습니다. 글에서 그 단어를 만나면 여기로 연결됩니다.

성능 측정

하네스

load test harness

하네스는 부하를 만들어 걸고 결과를 같은 방식으로 반복 측정할 수 있게 묶어 둔 도구 모음입니다.

p50 · p95 · p99

percentile latency

응답시간을 줄 세웠을 때 특정 위치의 값. p95 는 5%가 그보다 느렸다는 뜻입니다.

워밍업

warm-up

측정 앞부분을 버리는 구간. 그 구간은 정상 상태가 아니다.

arm(대조군)

arm

비교 실험에서 한 갈래의 실행. 한 변수만 다르고 나머지는 같아야 한다.

데이터베이스

커넥션 풀러

connection pooler

앱 커넥션 수천 개를 DB 커넥션 수십 개로 묶어 주는 중간 서버. RDS Proxy·PgBouncer 등.

트랜잭션 풀링

transaction pooling

커넥션 풀러가 트랜잭션 단위로 커넥션을 빌려주고 돌려받는 방식.

커넥션 풀

connection pool

앱이 DB 커넥션을 재사용하려고 들고 있는 목록. Spring Boot 기본은 HikariCP.

검증

뮤테이션 테스트

mutation testing

코드를 일부러 망가뜨린 뒤 테스트가 빨간불이 되는지 보는 방법.

설계

fail-closed

fail-closed

고장 났을 때 막는 쪽으로 넘어지는 설계. 반대는 fail-open.
